# Holool ERP Enterprise releases

Public Windows x64 installers and automatic-update metadata for Holool ERP Enterprise.

Download the installer from the latest GitHub release. Existing versions without an updater need a one-time manual installation of version 0.1.3 or newer. Later desktop versions check this repository at startup and every four hours. Updates can be disabled in Settings. A local recovery backup must succeed before an update is installed.

Installers are built locally. This repository does not use GitHub Actions and does not contain application source or business data.
